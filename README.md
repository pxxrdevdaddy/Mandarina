# HOW TO INSTALL
# XCODE INSTALLED IS REQUIRED
```bash
xcode-select --install
```
## Download the latest RELEASE (5.0) 
[Latest release](https://github.com/pxxrdevdaddy/Mandarina/releases/tag/v5.0)

## Open Terminal and write:

cd (DRAG YOUR MANDARINA FOLDER FROM FINDER) and press enter

## Once completed
execute 
```bash
./build.sh
```
 in terminal
## Drag Mandarina.app to the application folder and enjoy!

## HOW TO USE
Drag any file and press Command/Control/Shift to open menus.
